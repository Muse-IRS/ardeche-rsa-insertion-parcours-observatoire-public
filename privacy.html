Confidentialité et RGPD

Limiter les données dès la conception.

Ce site statique met à disposition de l'information générale. Il n'est pas un service de dépôt de dossiers administratifs.

Ce que contient le code publié

Absences applicatives

Ni compte utilisateur, ni formulaire, ni cookies applicatifs, ni stockage local applicatif, ni scripts d'analyse d'audience, ni générateur QR externe. Le QR code et la feuille de style sont servis localement avec le site.

Hébergement

GitHub Pages, une fois activé, sert les fichiers statiques. GitHub peut traiter des données techniques nécessaires à la connexion, notamment l'adresse IP et des journaux HTTP, selon ses propres conditions. Notre dépôt ne donne pas accès à ces journaux.

Liens vers les sources officielles

Ils sont ouverts seulement sur action du visiteur. Une politique de référent no-referrer limite la transmission de l'URL de provenance depuis nos pages ; chaque service tiers applique ensuite ses propres règles.

Aucune transmission de dossier personnel

Ne déposez jamais de numéro CAF, CER nominatif, pièce d'identité, courrier sensible ou donnée de santé dans une issue GitHub publique. Le canal privé de contact du projet reste à formaliser. Les droits sur les données personnelles peuvent être exercés auprès du responsable du traitement concerné ; la CNIL détaille les modalités générales.
